# Astrostatistics 4680/5680

This repository is the home for Astrostatistics course materials and supporting examples.

From the checkout root, source `scripts/set_repository_path.sh` to set `ASTROSTATISTICS_PHYSICS_4680_5680_PATH` in the current shell. Keep local inputs in the ignored `data/` directory and generated figures in the ignored `visuals/` directory.

## PCAT assignment

In the [transdimensional inference assignment](examples/pcat_transdimensional_assignment.ipynb), we use PCAT's public sampler to infer a variable number of Gaussian populations in a synthetic, unbinned event catalog. We state the generating assumptions and inspect the returned posterior. No observational data or saved result is required.
